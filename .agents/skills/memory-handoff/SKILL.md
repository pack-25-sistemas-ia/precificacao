# Memória e passagem de bastão

- Atualize `MEMORY.md` a cada marco, **só com fatos comprovados** (comando + resultado). Registre: o que está VERIFIED, o que falta, riscos, decisões (D-P*), armadilhas novas.
- Leia `MEMORY.md` e `AGENTS.md` antes de trabalhar; busque símbolos antes de abrir arquivos grandes; rode testes específicos durante e a suíte completa no fechamento.
- Não repita pesquisas documentadas (OPEN_SOURCE_AUDIT). Não sacrifique precisão matemática por economia de tokens.
